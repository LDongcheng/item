# FSJ 项目架构

> AI赋能商家平台 - 多商户系统

---

## 一、项目概述

**定位**: 面向草根创业者的低代码小程序生成平台，通过可视化拖拽和AI辅助定制，让不懂代码的创业者快速搭建自己的小程序。

**多商户架构**: 平台支持多个商家入驻，每个商家拥有独立的页面配置、组件数据和AI智能体。

## 三、前端架构

### 3.1 小程序端（wxApp）

原生小程序提供宿主能力，核心页面通过 WebView 内嵌 SPA 实现。

```
wxApp/
├── app.js / app.json / app.wxss     # 全局入口
├── pages/
│   ├── login/                        # 登录页（原生）
│   ├── webview/                      # WebView容器页
│   └── ...                           # 其他原生页
├── utils/                            # 工具函数
│   ├── mingdao-api.js                # 明道云API封装
│   └── auth.js                       # 登录鉴权
└── config/                           # 配置文件
```

**核心能力**:
- 导航栏管理（标题、返回按钮）
- TabBar 底部导航
- 微信登录 / 手机号登录
- JSSDK 通信（wx.mini.postMessage / bindmessage）

### 3.2 WebView SPA（内嵌页面）

采用**组件式开发 + 三分离架构**（HTML / CSS / JS 分离）。

```
webview-spa/                          # WebView SPA 根目录
├── index.html                        # 入口文件
├── css/
│   ├── base.css                      # 基础样式
│   ├── components.css                # 组件样式
│   └── pages.css                     # 页面样式
├── js/
│   ├── app.js                        # 应用初始化 & 路由
│   ├── bridge.js                     # 小程序通信桥接
│   ├── components/                   # 组件库
│   │   ├── agent-switcher.js         # 智能体切换组件
│   │   ├── merchant-login.js         # 商家登录组件
│   │   ├── phone-login.js            # 手机号登录组件
│   │   └── ...                       # 其他业务组件
│   └── pages/                        # 页面模块
│       ├── home.js                   # 首页
│       ├── merchant.js               # 商家后端
│       └── profile.js                # 个人中心
└── assets/                           # 静态资源
```

**三分离架构原则**:
- **HTML**: 只负责结构骨架
- **CSS**: 独立样式文件，按组件/页面组织
- **JS**: 独立逻辑文件，组件化模块化

### 3.3 H5端

H5 端与 WebView SPA 共享同一套组件库和路由逻辑，差异仅在于通信桥接层：
- 小程序环境 → 使用 `wx.mini.postMessage` 通信
- 纯 H5 环境 → 使用标准 Web API

## 四、组件式开发

### 4.1 组件规范

每个组件独立封装，遵循以下结构：

```
components/
├── {component-name}/
│   ├── {component-name}.js           # 组件逻辑（生命周期、数据处理）
│   └── {component-name}.css          # 组件样式
```

### 4.2 核心组件列表

| 组件 | 文件 | 功能 |
|------|------|------|
| 智能体切换 | `agent-switcher` | 切换不同AI智能体，加载对应12维记忆 |
| 商家登录 | `merchant-login` | 商家身份认证入口 |
| 手机号登录 | `phone-login` | 手机号+验证码登录 |
| 微信一键登录 | `wx-quick-login` | 小程序授权一键登录 |
| 更换手机号 | `change-phone` | 绑定/更换手机号 |
| 轮播图 | `swiper` | 图片轮播展示 |
| 功能列表 | `function-list` | 功能入口网格 |
| 商品网格 | `product-grid` | 商品展示 |
| AI分身 | `ai-agent` | 智能体交互界面 |

### 4.3 组件注册机制

```js
// componentRegistry.js
const registry = new Map();

function register(name, component) {
  registry.set(name, component);
}

function render(name, container, props) {
  const Component = registry.get(name);
  if (Component) {
    new Component(container, props);
  }
}
```

## 五、登录系统

### 5.1 登录方式

| 方式 | 场景 | 流程 |
|------|------|------|
| 手机号登录 | H5 / 通用 | 手机号 + 短信验证码 → 验证 → 登录 |
| 小程序一键登录 | 微信环境 | wx.login → code → 后端换取 token |
| 更换手机号 | 已登录用户 | 原手机验证 → 新手机验证 → 更新绑定 |

### 5.2 登录流程

```
┌──────────┐    ┌──────────────┐    ┌──────────────┐    ┌──────────┐
│ 用户触发  │ →  │ 选择登录方式  │ →  │ 调用登录API   │ →  │ 返回token │
│ 登录     │    │ 手机/微信     │    │ 明道云验证    │    │ 存储本地  │
└──────────┘    └──────────────┘    └──────────────┘    └──────────┘
```

### 5.3 Token 管理

- 登录后 token 存储在 `localStorage`（H5）或 `wx.setStorageSync`（小程序）
- 每次请求携带 token 进行鉴权
- token 过期自动跳转登录页

## 七、AI智能体 & 12维记忆管理

### 7.1 智能体架构

每个商家拥有独立的智能体实例，智能体统一采用 12维系统进行记忆管理。

```
智能体实例
├── 12维记忆系统
│   ├── 1维(寅) 技能     → Skill技能表
│   ├── 2维(卯) 想法     → 未经验证的创意、规划
│   ├── 3维(丙) 业务     → 项目、产生价值
│   ├── 4维(丁) 交流     → Agent与人交流数据
│   ├── 5维(庚) 制度     → 规范规章
│   ├── 6维(辛) 价值观   → 价值理念
│   ├── 7维(壬) 目标     → 上级目标
│   ├── 8维(癸) 计划     → 自己的计划
│   ├── 9维(丑) 信息     → 既定事实(不可变)
│   ├── 10维(辰) 人脉    → 用户画像
│   ├── 11维(未) 仓      → 文件资料
│   └── 12维(戌) 复盘    → 复盘总结
└── 智能体切换
    └── 切换时加载对应智能体的12维数据
```

### 7.2 智能体切换流程

```
用户选择智能体
    ↓
加载智能体配置（rowid、记忆策略）
    ↓
从12维系统检索对应数据
    ↓
初始化智能体上下文
    ↓
开始交互
```

### 7.3 12维检索策略

- **场景定位**: Agent 识别当前场景 → 定位对应维度 → 精准检索
- **组合检索**: 标签 + 标题 + 内容组合查询
- **分层检索**: 组织维度 → 个人维度 → 跨层级
