# 首页 & 组织需求文档

> 项目：AI赋能商家平台（fsj）| 更新日期：2026-05-01

---

## 零、项目定位

**碳基协同社区** — 以智能体为驱动的社区 + ERP 一体化系统。

- **社区属性**：通过组织（圈子）构建协同网络，用户在不同组织中发布内容、交流、协作
- **ERP属性**：围绕商家/企业的业务流，管理客户、项目、任务、话术等核心业务数据
- **智能体驱动**：一切业务通过智能体推进，智能体不是辅助工具，而是系统的核心引擎

> 智能体 = 业务推进器。不是"人用工具去管理业务"，而是"智能体主动推进业务，人配合执行"。

---

## 一、组织（圈子）概念

### 1.1 基本定义

- **组织**：类似圈子的概念，用户通过加入组织来浏览和发布内容
- **层级关系**：组织有父子级关系，父组织可以创建子组织
- **公开性**：每个组织有「公开」和「非公开」两种状态

### 1.2 可见性规则

| 条件 | 父组织能否看到子组织内容 |
|------|------------------------|
| 子组织公开 + 内容公开 | ✅ 可以看到 |
| 子组织公开 + 内容非公开 | ❌ 看不到 |
| 子组织非公开（内容状态无所谓） | ❌ 看不到 |

**核心规则**：组织非公开时，即使里面文章状态是公开的，父组织也看不到内容。

### 1.3 组织创建

- 用户可以在自己所在的组织中创建新的子组织
- 创建时可设置组织为「公开」或「非公开」

## 二、首页布局

### 2.1 顶部导航栏

| 位置 | 元素 | 说明 |
|------|------|------|
| 左上角 | 组织选择器 | 显示当前组织名称，点击下拉显示「我已加入的组织」列表，可切换组织 |
| 中间 | 搜索框 | 搜索当前组织内的内容 |
| 右上角 | 任务 | 点击跳转到最近要做的任务列表 |

### 2.2 首页内容区

从上到下依次为：

1. **轮播图**：全宽无外边距，支持左右滑动，自动轮播
2. **功能网格**：全宽无外边距，4列宫格（拜访计划、项目看板、话术库、复盘、目标追踪、知识库、排行榜、快捷任务）
3. **文章列表**：标题栏（「最新文章」+「查看更多」），每条文章是独立白色卡片（上下5px、左右10px外边距），包含标签、标题、作者、日期、阅读量

### 2.3 内容数据来源

- 首页展示的内容属于当前选中的组织
- 切换组织后，内容随之切换

## 三、技术实现要点

### 3.1 组织选择器

- 数据来源：当前用户已加入的组织列表
- 切换后刷新首页所有内容（轮播图、功能网格、文章列表）
- 需要缓存当前选中组织的ID

### 3.2 可见性过滤

- 后端/接口需根据当前组织ID + 公开性过滤内容
- 用户看到的内容 = 当前组织的内容 + 公开子组织的内容（子组织本身也是公开的）

### 3.3 任务入口

- 右上角任务按钮跳转到任务列表页
- 显示最近要做的任务（按截止日期排序）
