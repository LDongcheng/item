# 明道云 HAP 集成方案

> 项目：AI赋能商家平台（fsj）| 更新日期：2026-05-01

---

## 一、HAP 定位

每个商家入驻时，系统自动为其创建一个独立的明道云 HAP 应用，作为该商家的**后端数据引擎**。

- **商家 = 一个 HAP 应用**：数据隔离，互不影响
- **智能体驱动**：通过 16 个技能直接操作 HAP 数据表，实现业务自动化
- **低代码扩展**：商家后期可在 HAP 内自行搭建视图、流程，无需改代码

---

## 二、HAP API 调用方式

所有 HAP 操作统一通过 Coze Workflow API 转发，不走直连。

### 2.1 数据维护 / 建表 API

```bash
curl -X POST 'https://api.coze.cn/v1/workflow/stream_run' \
-H "Authorization: Bearer sat_PsqZd6JJl9qOPZoT30rPv2gLKAVIMXGMmIp38VzXXIRU77nzgzk09yvcFwNT8Z4h" \
-H "Content-Type: application/json" \
-d '{
  "workflow_id": "7634531869195796499",
  "parameters": {
    "appkey": "30916c7b804fec5a",
    "content": "操作描述（如：创建一条流数据）",
    "org": "组织 rowid",
    "rowid": "记录 rowid（新增时可为空或传预定义值）",
    "sign": "签名（base64 编码）"
  }
}'
```

### 2.2 参数说明

| 参数 | 类型 | 说明 |
|------|------|------|
| `appkey` | string | HAP 应用的 appkey，标识目标应用 |
| `content` | string | 操作指令/内容描述，智能体根据此解析具体动作 |
| `org` | string | 当前操作的组织 rowid |
| `rowid` | string | 目标记录 rowid，新建时不需要 |
| `sign` | string | 请求签名，用于鉴权 |

## 三、16 个技能清单

HAP 模型配置了 16 个技能，覆盖工作表和记录的**增删改查**全生命周期。

### 3.1 记录操作（CRUD）

| # | 技能 | 操作 | 说明 |
|---|------|------|------|
| 1 | 批量创建工作表记录 | CREATE (batch) | 一次性创建多条记录 |
| 4 | 创建工作表行记录 | CREATE (single) | 创建单条记录 |
| 2 | 批量删除工作表中的多个记录 | DELETE (batch) | 按条件删除多条记录 |
| 6 | 通过 id 删除工作表中的行记录 | DELETE (single by id) | 按 ID 删除单条 |
| 7 | 根据 ID 删除工作表 | DELETE (table) | 删除整张表 |
| 3 | 批量更新多个记录的相同字段值 | UPDATE (batch) | 批量改同一字段 |
| 15 | 通过 id 更新工作表中的行记录 | UPDATE (single by id) | 改单条记录 |

### 3.2 工作表操作

| # | 技能 | 操作 | 说明 |
|---|------|------|------|
| 5 | 创建包含字段与元数据的工作表 | CREATE TABLE | 建表 + 定义字段结构 |
| 10 | 通过工作表 ID 获取工作表结构信息 | READ TABLE schema | 获取表结构定义 |
| 11 | 获取工作表的行记录列表 | READ TABLE records | 查询表内数据 |
| 16 | 更新工作表的属性或字段 | UPDATE TABLE | 修改表结构/属性 |

### 3.3 查询与统计

| # | 技能 | 操作 | 说明 |
|---|------|------|------|
| 9 | 获取工作表记录的透视表汇总数据 | AGGREGATE | 透视表/汇总统计 |
| 12 | 按名称精确匹配查找部门 | QUERY department | 返回部门 ID、名称、路径 |
| 13 | 按名称精确匹配查找成员 | QUERY member | 返回用户账号 ID、姓名等 |
| 14 | 获取地区信息 | QUERY region | 支持指定 ID 与模糊搜索 |

### 3.4 应用信息

| # | 技能 | 操作 | 说明 |
|---|------|------|------|
| 8 | 获取应用信息 | READ app info | 返回应用下的工作表、自定义页面信息 |

## 四、智能体与 HAP 的协作流程

```
用户输入需求
    ↓
智能体解析意图
    ↓
匹配对应的 HAP 技能
    ↓
调用 Coze Workflow API → 操作明道云 HAP 数据
    ↓
返回结果给用户
```

**示例场景**：

1. **创建客户**：智能体调用「创建工作表行记录」，写入客户信息到客户表
2. **批量更新状态**：智能体调用「批量更新多个记录的相同字段值」，将一批客户状态改为「已签约」
3. **创建数据表**：智能体调用「创建包含字段与元数据的工作表」，为商家新建一张业务表
4. **查询统计**：智能体调用「获取工作表记录的透视表汇总数据」，生成销售报表

## 五、商家入驻流程

```
商家注册/登录
    ↓
系统自动创建 HAP 应用（appkey 分配）
    ↓
初始化基础数据表（客户、项目、任务等）
    ↓
绑定商家账号，创建对应组织
    ↓
商家首页可见，开始使用
```

## 六、注意事项

1. **签名安全**：每次请求都需要携带有效的 sign 签名，签名算法需后端维护
2. **appkey 隔离**：每个商家独立 appkey，确保数据不串
3. **流式响应**：API 使用 `stream_run` 端点，支持流式返回结果
4. **content 字段**：操作指令以自然语言描述，智能体负责解析和执行
