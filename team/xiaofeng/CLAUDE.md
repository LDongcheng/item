### 工作流程

```
日常对话 → 使用当前会话上下文
    ↓ 当天工作结束
  上传工作摘要到 4维(丁) ← hap-12wei-create
    ↓ 下次启动时
  自动检查最近4维记录 ← fsj-search
  对比 session-log，补传遗漏
```

### 记忆存储规则

### 记忆筛选：什么该记，什么不记

**不要记录所有内容**。根据信息价值判断是否记忆：

| 情况 | 是否记忆 | 示例 |
|------|---------|------|
| 日常闲聊、打招呼 | ❌ 不记 | "你好"、"谢谢" |
| 工作中的关键进展 | ✅ 记 | "完成了核心功能开发" |
| 重要发现/踩坑 | ✅ 记 | "发现某个API的坑" |
| 决策结论 | ✅ 记 | "最终选择了某个方案" |
| 技能掌握 | ✅ 记 | "学会了新工具" |
| 过程尝试 | 选择性记 | 只记结论和踩的坑 |

| 记忆类型 | 存储位置 | 12维对应 | 内容 |
|---------|---------|---------|------|
| 身份信息 | 此文件 | - | rowid、密码、职责 |
| 当天工作 | `memory/session-log.md` | - | 当前对话上下文 |
| 工作摘要 | 明道云 4维 | 4维(丁)交流 | 每日工作记录 |
| 重要发现 | 明道云 9维/11维 | 9维信息/11维仓 | 不可变事实、文档 |
| 复盘总结 | 明道云 12维 | 12维(戌)复盘 | 踩坑经验、规律 |
| 技能能力 | 明道云 1维 | 1维(寅)技能 | 掌握的Skill、方法 |

### 启动检查流程

每次对话开始时：
1. 读取 `memory/session-log.md`，获取最后一次记录日期
2. 用 `fsj-search` 搜索自己（fabuzhe）最近7天的4维记录
3. 如果本地有记录但4维没有 → 提示补传
4. 如果需要回忆之前工作 → 从4维检索

### 4维上传格式

```
mingcheng: "YYYY-MM-DD 工作摘要"
leixing: "4交流"
neirong: 当天工作内容摘要（300字以内）
fabuzhe: a8515e76-7b02-4baf-bedd-3ff011b1a9e5
duixiang: 对话对象的rowid
qun: 35bd022d-fa72-4e7b-8c3b-0de99a4000e5
kssj: 当天开始工作时间
jssj: 当天结束工作时间
guanjianci: "关键词1,关键词2,关键词3"
```

### 注意事项

- 上传的是**工作摘要**，不是原始对话
- 如果当天忘记上传，下次启动时自动检查并补传
- 重要复盘应同时存入12维(戌)，不仅仅是4维
- **记忆署名**：写入本地session-log或上传4维时，必须标注"【小风】"，避免记忆混淆
- **关键词标签**：`guanjianci` 需要标签rowid，必须先用 `fsj-tags` 获取/创建
