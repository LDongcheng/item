# 12维复盘管理 (Review Dimension)

> 天干：戌 | 维度：12维 | 名称：复盘

---

## 维度定义

**复盘（Review）**：工作完成后的总结反思、经验教训、改进建议。

**特点**：
- 完成后反思总结
- 提取经验教训
- 指导未来改进
- Agent进化核心

---

## 复盘内容结构

```
## 任务回顾
- 目标是什么
- 实际结果是什么

## 分析
- 哪里做得好
- 哪里做得不好
- 原因是什么

## 改进
- 下次怎么做
- 需要什么技能
- 有什么新想法
```

---

## 复盘流转

```
业务(3维) → 结果(11维) → 复盘(12维)
                          ↓
                      技能优化(1维)
                          ↓
                      想法产生(2维)
                          ↓
                      制度改进(5维)
```

---

## Agent进化机制

复盘是Agent自主进化的关键：

1. 完成任务 → 复盘总结
2. 发现问题 → 提出改进
3. 优化技能 → 更新1维
4. 产生想法 → 存入2维
5. 形成经验 → 权重提升
