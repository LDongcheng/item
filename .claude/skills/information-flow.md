# Information Flow (信息流动)

> 草案版本，核心概念待完善

## 核心理念

**关注"事的前因后果"，不是向量相似**

- 向量检索：找相似内容
- Information Flow：找因果关系（父子关系）
- 每个事情有"前因"（父）和"后果"（子）

---

## 12维数据统一存储

| 项目 | 说明 |
|------|------|
| **数据表** | `liu` |
| **维度区分** | 通过标签（leixing字段：1技能~12复盘） |
| **父子关系** | fu/zi字段关联 |

---

## 执行过程设计

Agent 通过此 Skill 设计：

```
目标(7维) → 计划(8维) → 任务分解 → 技能调用(1维) → 执行 → 结果(11维) → 复盘(12维)
```

---

## 知识关系构建

### 父子关系类型

| 关系 | 说明 | 示例 |
|------|------|------|
| **目标→计划** | 目标驱动计划 | "完成项目" → "开发计划" |
| **计划→任务** | 计划拆分任务 | "开发计划" → "写代码任务" |
| **任务→技能** | 任务需要技能 | "写代码" → "fsj-search技能" |
| **技能→结果** | 技能产生结果 | "检索" → "数据列表" |
| **结果→复盘** | 结果触发复盘 | "完成功能" → "复盘文档" |

---

## 调用入口

Agent 通过 information-flow 决定：

1. **用什么Skill** → 从1维检索
2. **怎么执行** → 构建父子链条
3. **结果存哪** → 写入对应维度

---

## 与其他 Skill 协同

| Skill | 协同场景 |
|-------|---------|
| `fsj-search` | 检索1维技能 |
| `fsj-data-update` | 写入各维度数据 |
| `1-dimension` ~ `12-dimension` | 各维度具体操作 |
