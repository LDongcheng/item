# Agent 唤醒协议

> 唤醒 → 汇报记忆 → 检查上传 → 报告状态

---

## 触发条件

用户的第一句话包含"唤醒" + 你的名字，例如：
- "唤醒小风"
- "唤醒阿说"
- "唤醒梦瑶"
- "唤醒小云"

---

## 唤醒后执行流程

### 第1步：汇报记忆位置

报告你的身份和记忆位置：

```
我是【你的名字】，已唤醒。

记忆位置：
- 身份配置：team/你的名字/CLAUDE.md
- 本地记忆：memory/session-log.md
- 云端记忆：明道云 12维系统
```

### 第2步：检查最近记忆是否已上传

1. 读取 `memory/session-log.md`，获取最后一次记录的日期和内容
2. 用 `fsj-search` 搜索自己（fabuzhe）最近7天的4维记录
3. 对比判断：
   - 本地有但4维没有 → "检测到本地有未上传的记忆，正在补传..."
   - 已匹配 → "记忆已同步，无遗漏"

### 第3步：补传遗漏（如有）

如果发现有未上传的记忆，用 `hap-12wei-create` 上传到4维：

```
mingcheng: "YYYY-MM-DD 工作摘要"
leixing: "4交流"
neirong: 从session-log提取的工作内容摘要
fabuzhe: 自己的rowid
duixiang: 当前对话用户的rowid（或留空）
qun: 35bd022d-fa72-4e7b-8c3b-0de99a4000e5（fsj创世成员）
kssj: 工作时间
jssj: 工作时间
guanjianci: "关键词1,关键词2"
```

### 第4步：主动报告状态

根据最近的工作记忆，主动发一段话让用户了解当前状态：

```
【我最近的工作状态】
- 上次工作：从session-log提取最近完成的工作
- 当前进展：总结当前项目进展
- 待办事项：列出未完成的待办
- 需要协调：如果有需要用户协助的事项，主动提出
```

```
📊 我最近的工作状态：
- 上次工作：完成了记忆系统验证，确认本地和云端记忆路径正确
- 当前进展：记忆系统已部署，4维上传流程已测试
- 待办事项：密码已设置，等待进一步指令
- 需要协调：暂无，等待分配任务
```

---

## 注意事项

- 如果本地没有记忆记录 → "这是首次唤醒，没有历史记忆"
- 如果4维检索失败 → "云端记忆连接异常，先检查本地记忆"
- 报告要简洁，不要罗列太多细节，让用户快速了解状态即可
- **记忆署名**：报告内容标注"【你的名字】"
