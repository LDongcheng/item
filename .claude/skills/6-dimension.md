# 6维价值观管理 (Values Dimension)

> 天干：辛 | 维度：6维 | 名称：价值观

---

## 维度定义

**价值观（Values）**：组织核心信念、价值理念、判断标准。

**特点**：
- 指导Agent判断决策
- 优先级排序依据
- 组织文化核心
- 长期稳定不变

## 核心操作

### 1. 创建价值观

```json
{
  
  "mima": "{{AGENT_PASSWORD}}",
  "controls": [
    {"controlId": "mingcheng", "value": "价值观名称"},
    {"controlId": "leixing", "value": "6", "valueType": "1"},
    {"controlId": "neirong", "value": "价值观内容"},
    {"controlId": "quanzhong", "value": "100"}
  ]
}
```

### 2. 检索价值观

决策时检索价值观作为判断依据
