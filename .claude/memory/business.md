# fsj 业务需求要点

## 产品定位

**AI赋能商家平台** - 面向草根创业者的低代码小程序生成平台

## 目标用户

- 草根创业者、对AI焦虑的人群
- 技术背景弱，希望快速搭建应用
- 需要AI工具提升效率

## 核心价值

- **对创业者**: 零代码搭建小程序，AI辅助降低成本
- **对平台**: 通过组件化和AI协同，逐步提升AI完成度
- **AI完成度目标**: 30%(当前) → 70%(阶段二) → 99%(阶段三)

## 商家后台功能

### 门店装修（页面设计器）

四区布局：页面树 | 组件库 | 属性面板 | 预览区域

视图切换：页面视图 | 底部导航栏视图 | 全局设置视图

### 组件系统

**通用组件**: 轮播图、功能列表、图片、文本、商品网格、公告、标签页、内容列表、搜索框、注册登录

**AI特色组件**: AI分身、AI任务、AI知识库、组织圈子（通过Webview内嵌）

**DIY组件**: 用户自定义，AI辅助定义数据结构

### 定制化需求管理

状态流程：
待处理 → AI处理中 → 待确认 → 用户满意/不满意 → 人工处理中 → 已完成

### 小程序打包

流程：
1. 接收JSON配置
2. 复制基础框架
3. 生成页面代码
4. 生成app.json
5. 下载图片
6. ZIP打包下载

## 小程序端功能

- 通用功能：注册登录、个人中心、消息通知
- 商城功能：商品列表、购物车、订单、支付
- AI卡牌训练：Webview内嵌，像素化UI

## 算法推荐系统

**neirong表设计**:
- 内容ID、各类基数（评论、收藏、转化等）
- 因子配置（商家可调权重）
- 权重公式计算

**推荐流程**:
neirong表按权重排序 → 获取ID列表 → 业务表取数 → 渲染组件

## 数据架构

### 数据来源分类

- **通用数据**: 系统预置表（商品、文章、知识库）
- **自定义数据**: 用户在明道云创建的表

### 组件数据绑定字段

- `dataSourceType`: common/custom
- `dataSourceKey`: product/article/knowledge/custom
- `sorting`: 排序规则
- `filters`: 过滤条件
