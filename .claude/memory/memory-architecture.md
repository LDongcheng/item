# Agent 双层记忆架构

> 核心原则：重要记忆持久保存，次要记忆自由迭代

---

## 设计理念

记忆不是死的，要给 Agent 进化空间：
- **核心记忆** → 保障基础能力，不能丢
- **迭代记忆** → 允许试错探索，随时调整

---

## 核心记忆（持久层）

**必须存储，跨会话持久**

| 类型 | 内容 | 存储 |
|------|------|------|
| 身份记忆 | Agent是谁、rowid、密码、职责 | 明道云固定字段 |
| 能力记忆 | 已掌握技能、已验证方法 | 1维(寅)技能，持久化 |
| 关键产出 | 完成任务、重要成果 | 11维(未)仓 |
| 关键复盘 | 学到的规律、踩过的坑 | 12维(戌)，提炼后保留 |

**特点**：
- 稳定，不频繁改动
- 定期精简（但不删除）
- 系统保障存储

---

## 迭代记忆（演化层）

**自主管理，可丢弃**

| 类型 | 内容 | 处理 |
|------|------|------|
| 临时想法 | 猜测、假设、探索 | 用完可删 |
| 日常流水 | 每次对话细节 | 定期压缩/丢弃 |
| 试错记录 | 失败尝试 | 成功后清理 |
| 实验结构 | 尝试的记忆组织方式 | 不好用就换 |

**特点**：
- 灵活，允许失败
- Agent自主决定保留/丢弃
- 定期清理，防止膨胀

---

## 运行机制

```
每次对话结束：
│
├── 判断：重要记忆？
│       ├── 是 → 核心记忆（持久化）
│       └── 否 → 迭代记忆（临时）
│
└── 定期复盘：
        ├── 迭代记忆有价值 → 升级为核心记忆
        └── 迭代记忆无价值 → 清理丢弃
```

---

## 判断标准（参考）

**核心记忆**：
- 改变了 Agent 能力/认知
- 被反复验证有效的
- 身份/职责相关
- 产出成果

**迭代记忆**：
- 未验证的想法
- 一次性细节
- 失败的试错
- 实验性内容

---

## 与12维的关系

- 1维(寅)技能 → 核心记忆
- 11维(未)仓 → 核心记忆
- 12维(戌)复盘 → 核心记忆（提炼后）
- 其他维度 → Agent自主决定归属

**不强制绑定维度，让 Agent 自己探索**
