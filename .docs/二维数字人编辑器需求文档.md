# 二维数字人编辑器需求文档

## 一、功能概述

### 1.1 产品定位
为AI智能体提供可视化形象编辑功能，用户可自定义数字人的外观（身体、眼睛、头发、衣服等），并支持背景场景设置。

### 1.2 核心价值
- **可视化AI形象**：让AI智能体有具体形象，增强用户互动体验
- **个性化定制**：用户可DIY数字人外观，体现个性化
- **游戏化体验**：与卡牌系统结合，形象可作为角色卡牌的一部分

### 1.3 使用场景
- AI智能体对话界面的人物展示
- 角色卡牌的形象定义
- 任务/剧情场景中的NPC展示

## 二、图层系统设计

### 2.1 图层层级规范

采用**从下到上**的渲染顺序，底层先渲染，上层覆盖：

```
┌─────────────────────────────────────┐
│  Layer 4: 头发层 (头发、帽子等DIY)   │  ← 最上层
├─────────────────────────────────────┤
│  Layer 3: 饰品层 (眼镜等DIY)         │
├─────────────────────────────────────┤
│  Layer 2: 表情层 (眼睛、嘴巴)        │
├─────────────────────────────────────┤
│  Layer 1: 服装层 (衣服、配饰)        │
├─────────────────────────────────────┤
│  Layer 0: 身体层 (基础轮廓)          │  ← 最底层
├─────────────────────────────────────┤
│  Background: 背景层 (场景图)         │
└─────────────────────────────────────┘
```

### 2.2 图层分类原则

| 分类 | 层级位置 | 特点 | 示例 |
|------|---------|------|------|
| **通用层** | 底层(Layer 0-1) | 变化少，基础形状 | 身体轮廓、基础服装 |
| **表情层** | 中层(Layer 2) | 动态变化，表达情绪 | 眼睛、嘴巴、眉毛 |
| **DIY层** | 上层(Layer 3-4) | 高度可定制，个性化 | 头发、饰品 |

### 2.3 图层属性定义

每个图层元素包含以下属性：

```json
{
  "layerId": "hair_001",
  "layerName": "头发",
  "layerLevel": 4,
  "visible": true,
  "opacity": 1.0,
  "position": { "x": 0, "y": -10 },
  "size": { "width": 100, "height": 80 },
  "imageSource": "assets/hair/style_001.png",
  "color": "#333333",
  "animation": null
}
```

### 5.2 渲染流程

```javascript
// 渲染函数伪代码
function renderCharacter(characterData) {
  // 1. 清空画布
  clearCanvas();

  // 2. 绘制背景
  drawBackground(characterData.background);

  // 3. 按层级顺序渲染
  const sortedLayers = characterData.layers.sort(
    (a, b) => a.layerLevel - b.layerLevel
  );

  for (const layer of sortedLayers) {
    for (const element of layer.elements) {
      if (element.visible) {
        drawElement(element);
      }
    }
  }
}
```

### 5.3 图层叠加实现

```javascript
// Canvas 图层渲染示例
class LayerRenderer {
  constructor(canvas) {
    this.canvas = canvas;
    this.ctx = canvas.getContext('2d');
  }

  drawBackground(bgData) {
    if (bgData.type === 'image') {
      const img = loadImage(bgData.source);
      this.ctx.drawImage(img, 0, 0, this.canvas.width, this.canvas.height);
    } else if (bgData.type === 'color') {
      this.ctx.fillStyle = bgData.color;
      this.ctx.fillRect(0, 0, this.canvas.width, this.canvas.height);
    }
  }

  drawElement(element) {
    const img = loadImage(element.imageSource);

    this.ctx.save();

    // 设置透明度
    this.ctx.globalAlpha = element.opacity || 1.0;

    // 应用颜色（可选）
    if (element.color) {
      this.ctx.filter = `colorize(${element.color})`;
    }

    // 绘制元素
    this.ctx.drawImage(
      img,
      element.position.x + this.canvas.width / 2,
      element.position.y + this.canvas.height / 2,
      element.size.width,
      element.size.height
    );

    this.ctx.restore();
  }
}
```

### 10.4 导出数据格式

```json
[
  ["FFFFFF", null, "000000", "FF0000"],
  [null, "00FF00", "00FF00", null],
  ["0000FF", "0000FF", null, "FFFF00"]
]
```

- 颜色值：6位HEX字符串（不带#号）
- 透明像素：null

### 10.5 与虚拟世界集成

导出的JSON数据可直接用于 `juese.json` 格式，配合 `color.json` 调色板在 `pixel-canvas` 页面渲染角色/建筑。
