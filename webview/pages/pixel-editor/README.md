# 像素画编辑器

## 使用说明

### 启动方式

1. 运行 `启动服务器.bat` 启动本地服务器
2. 访问 `http://localhost:8080`

### 页面切换

修改 `app.js` 中的默认页面：

```javascript
// 加载像素角色展示页面
this.loadPage('pixel-canvas');

// 或加载像素编辑器页面
this.loadPage('pixel-editor');
```

### 编辑器功能

1. **画笔工具** - 点击画布绘制像素
2. **橡皮擦** - 点击画布清除像素（设为透明）
3. **填充工具** - 洪水填充连续区域
4. **透明色** - 选择后绘制的像素为透明
5. **调色板** - 从预定义的110种颜色中选择
6. **画布尺寸** - 可调整4-64像素范围
7. **导出JSON** - 将像素数据导出为二维数组格式

### JSON格式说明

导出的JSON数据格式：

```json
[
  ["FFFFFF", null, "000000", ...],
  ["FF0000", "00FF00", null, ...],
  ...
]
```

- 有颜色的像素：6位HEX颜色值（如 "FF0000"）
- 透明像素：null

### 与现有系统集成

编辑器导出的JSON可以直接用于 `juese.json` 格式，配合 `color.json` 调色板在虚拟世界中渲染角色/建筑。
