# 孚世界技能 12 - 复盘

本技能让 OpenClaw 智能体对孚世界「复盘」维度数据进行建表与增删改查，**通过调用 HAP 相关技能**在明道云中操作「复盘12」表。

## 触发条件

- 用户或任务涉及：复盘、项目复盘、问题总结、改进建议、多维度分析
- 需要对「复盘」表进行创建、查询、新增、修改、删除

## 前置依赖

- 已配置 HAP 应用执行 MCP 或掌握 HAP V3 API 鉴权
- 参考：`01/inn/hap/hap-as-database`、`01/inn/hap/hap-v3-api`、`01/inn/hap/hap-mcp-usage`

## 工作表标识

- **表名**：复盘12
- **明道云工作表 ID**：`69b028cb234371657be46a96`

## 字段规范

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| title | 文本 | 是 | 复盘名称，必须英文名 |
| content | 长文本 | 是 | 必须 md 格式，复盘的具体内容 |
| json | 长文本/JSON | 否 | **建议填写**：记录 01-11 维度的组合（如技术+业务、制度+理念等），便于全面分析 |

## 执行步骤

1. **建表**：使用 HAP MCP 或 hap-as-database 规范创建工作表，字段至少 title、content、json。
2. **增**：HAP `POST /app/worksheets/{worksheetId}/rows`，worksheetId 为上表 ID，传入 title、content；建议在 json 中记录涉及的维度组合（01-11）。
3. **删**：HAP 删除行接口，按行 id 或条件删除。
4. **改**：HAP 更新行接口，按行 id 更新 title、content、json。
5. **查**：HAP 列表接口，支持按 title、content、json 或维度组合筛选；选项字段使用 key。

## 复盘组合说明

- 复盘时应记录技术、创意、业务、交流、制度、理念、目标、任务、信息、人脉、仓等维度的组合。
- 示例：技术+业务复盘（分析技术实现与业务目标的匹配度）；制度+理念复盘（评估制度与理念的一致性）。
- 通过多维度组合可更全面分析项目问题与改进方向。json 中可含维度标签或关联记录 id。

## 注意事项

- content 为 Markdown；空间表与主表 title、content、json 一致以便备份。
- 建议 json 中体现 01-11 的维度组合，便于检索与统计。
