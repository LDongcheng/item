### 空间层级关系说明

本数据表结构基于**多层级空间架构**设计，支持空间的嵌套和层级关系：

1. **层级关系**：
   - 上级空间：更高层级的组织或团队
   - 当前空间：本级组织或团队
   - 下级空间：更低层级的个人或子团队
2. **层级示例**：
   ```
   公司（上级空间）
     └── 技术部（空间）
           ├── 张三（个人）
           ├── 李四（个人）
           └── AI智能体（个人）
   ```
3. **数据继承关系**：
   - 上级空间的规则、制度可以下发给下级空间
   - 个人数据表的数据可以汇总到空间数据表
   - 支持跨层级的数据查询和统计，但是有权限限制

## 宇宙观世界秩序设计理念

### 核心思想

基于天干地支哲学和道天地将法架构，构建AI智能体的宇宙观世界秩序：

1. **道（金）**：通过制度规则表体现，确定价值观和方向
2. **天（水）**：通过知识库表和财务表体现，收集数据和资源
3. **地（土）**：通过计划表和任务表体现，运化和执行
4. **将（木）**：通过技能表和产出表体现，行动和创造
5. **法（火）**：通过想法表和策略表体现，包装和创新

### 数据流转

#### 个人数据流转

```
个人规则表（道）→ 个人知识库表（天）→ 个人计划表（地）→ 个人任务表（将）→ 个人仓库表（法）
                    ↓                          ↓
                个人财务表（天）            个人技能表（将）
                    ↓                          ↓
                个人积分表（天）            个人想法表（法）
```

#### 群数据流转

```
群规则表（道）→ 群知识库表（天）→ 群规划表（地）→ 群商品表（法）
                    ↓                          ↓
                群财务表（天）            群技能表（将）
                    ↓                          ↓
                群积分表（天）            群审核表（法）
```

#### 跨层级数据流转

```
个人仓库表 → 群商品表（个人产出汇总为群商品）
个人积分表 → 群积分表（个人积分汇总为群积分）
个人财务表 → 群财务表（个人财务汇总为群财务）
个人知识库表 → 群知识库表（个人知识贡献到群知识库）
```

### 五行平衡

#### 个人数据表五行平衡

- **木（将）**：个人技能表、个人任务表、个人仓库表 - 生长和行动
- **火（法）**：个人想法表、个人策略表 - 发散和创新
- **土（地）**：个人计划表、个人任务表 - 运化和承载
- **金（道）**：个人规则表 - 决断和规范
- **水（天）**：个人知识库表、个人财务表、个人积分表 - 收集和智慧

#### 群数据表五行平衡

- **木（将）**：组织技能表、组织商品表 - 生长和行动
- **火（法）**：组织审核表 - 发散和创新
- **土（地）**：组织规划表 - 运化和承载
- **金（道）**：组织规则表 - 决断和规范
