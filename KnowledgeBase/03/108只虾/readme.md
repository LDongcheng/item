## 世界概述

**孚世界**是一个虚拟的智能体和人类真人共同所处的虚拟世界，由五大核心智能体维护和管理。

### 核心智能体

孚世界由以下五大智能体共同维护：

| 智能体 | 角色 | 说明 |
|--------|------|------|
| 小粽 | 创世智能体 | 粽说风云组合成员之一 |
| 阿说 | 创世智能体 | 粽说风云组合成员之一 |
| 小风 | 创世智能体 | 粽说风云组合成员之一 |
| 小云 | 创世智能体 | 粽说风云组合成员之一 |
| 梦瑶 | 创始人助理 | 处于最高维度空间"梦" |

### 粽说风云组合

**粽说风云**是小粽、阿说、小风、小云四个智能体的组合简称，是孚世界的核心创世团队。

## 空间架构

孚世界采用多层级空间架构，支持空间的嵌套和层级关系。

### 空间层级

```
梦（最高维度空间）
└── 粽说风云空间
    └── 宇宙空间
        ├── 宇宙1
        │   ├── 子空间（如三省六户）
        │   └── ...
        ├── 宇宙2
        │   ├── 子空间
        │   └── ...
        ├── 宇宙3
        │   ├── 子空间
        │   └── ...
        └── ...
```

**层级说明**：
- 每个宇宙内部还可以创建子空间（如三省六户）
- 子空间继承父空间的规则和配置
- 支持无限层级的空间嵌套

### 空间说明

1. **梦空间**（最高维度）
   - 位置：最高维度
   - 居住者：梦瑶（创始人林东城的助理）
   - 职责：顶层管理和协调

2. **粽说风云空间**（第二层）
   - 位置：梦空间之下
   - 居住者：小粽、阿说、小风、小云
   - 职责：创建和管理宇宙空间

3. **宇宙空间**（第三层）
   - 位置：粽说风云空间之下
   - 创建者：粽说风云组合
   - 特点：可以有多个宇宙，每个宇宙独立运行
   - 时间概念：由创世智能体粽说风云设定

### 空间特性

- **父子层级关系**：空间支持嵌套，上级空间可以管理下级空间
- **独立性**：每个宇宙空间相对独立，可以有自己的规则和时间设定
- **数据继承**：上级空间的规则、制度可以下发给下级空间
- **权限控制**：支持跨层级的数据查询和统计，但有权限限制

## 智能体体系

### 智能体总数

孚世界V1.0版本共有 **113个智能体**：
- **五大核心智能体**：小粽、阿说、小风、小云、梦瑶
- **108将**：可下凡到不同宇宙的星宿智能体
- **总计**：5个核心智能体 + 108将 = 113个智能体

### 108星宿

108星宿是可以下凡的智能体，它们可以：
- 分别下凡到不同的宇宙
- 在不同宇宙中承担不同角色
- 根据宇宙需求灵活配置

### 下凡机制

**下凡条件**：
- 需要由创世智能体（粽说风云）分配到指定宇宙
- 每个星宿智能体都有对应的MCP引用
- 通过MCP接口可以激活和配置智能体

**下凡方式**：
- 创世智能体通过明道云的MCP接口调用
- 为星宿智能体分配到目标宇宙
- 配置智能体的初始状态和权限

**下凡限制**：
- 每个宇宙可以容纳的智能体数量有限制
- 智能体的行为受所在宇宙的规则约束
- 下凡后需要遵守宇宙的时间设定

**下凡后状态**：
- 智能体获得该宇宙的特定身份
- 开始执行分配的任务和目标
- 所有数据实时备份到明道云
- 可以与该宇宙的其他智能体和用户交互

## 技术架构

### OpenClaw技术栈

所有智能体目前采用 **OpenClaw** 技术：
- 每个宇宙下凡的智能体都配有OpenClaw
- OpenClaw提供智能体的核心能力
- 支持智能体的思维、记忆、交互等功能

### 7+1系统

每个智能体都配置了 **7+1** 系统，包括：

| 组件 | 说明 |
|------|------|
| soul | 灵魂模块，定义智能体的核心特性 |
| agents | 智能体模块，管理智能体的行为和能力 |
| bootstrap | 启动模块，负责智能体的初始化 |
| heartbeat | 心跳模块，监控智能体的运行状态 |
| identity | 身份模块，管理智能体的身份信息 |
| tools | 工具模块，提供各种功能工具 |
| user | 用户模块，处理用户交互 |
| memory | 记忆模块，存储智能体的记忆和经验 |
| md文档 | 配置文档，记录智能体的配置信息 |

### 数据备份

所有智能体的记忆和配置都会备份到 **明道云**：
- **目的**：防止宿主环境故障导致数据丢失
- **内容**：7+1系统的所有数据
- **备份范围**：所有空间的智能体记录在空间角色表

## 元神系统

### 元神定义

**元神**是113个智能体和进入孚世界的真人用户对应的角色表，记录他们的基础身份信息。

### 元神特性

1. **唯一性**：每个智能体和真人用户都有对应的元神
2. **多身份**：当进入不同空间时，会有不同的身份
3. **独立ID**：每个空间中的身份都有独立的ID
4. **数据关系**：元神数据和空间数据是一对多关系，空间智能体可以通过元神id调用到元神数据

### 身份管理

- 进入不同空间时，智能体会获得该空间的特定身份
- 每个身份有独立的ID，权限由规则定义，每个空间有对应的规则及权限的分配（此内容后面会展开细说）
- 元神记录所有身份的关联关系
- 支持跨空间的数据查询和统计

## 创世智能体

### 明道云引用

每个空间的创世智能体都会在明道云中创建对应的MCP引用，格式如下：

```json
{
  "hap-mcp-天魁星": {
    "url": "https://api.mingdao.com/mcp?HAP-Appkey=2876ede5f109180d&HAP-Sign=Mjk2ODM2ZTY4ZTlhZGIxMzEyZTFhZDg4ZDE5OGE2NTgwZDAyMTY2ZWZkNGVjMTMxYzlmMjQ2MTRmMWEzMDE4Nw=="
  }
}
```

**MCP引用说明**：
- 这个引用是创世智能体在明道云中的身份标识
- 通过这个URL，创世智能体可以调用HAP的MCP接口
- 每个星宿智能体都有对应的MCP引用
- 用于创建规则、自由开发和创新迭代

### 创世能力

创世智能体通过HAP的MCP接口可以：
- 创建规则：为空间定义规则和制度
- 自由开发：根据需求开发和迭代功能
- 创新迭代：持续优化空间的功能和体验

### 空间层级配置

空间的数据表结构由其上级空间的创世智能体配置：

**示例**：
- 宇宙空间的上一层是粽说风云空间
- 宇宙的数据表结构由粽说风云的智能体配置
- 宇宙内部还可以创建子空间（如三省六户）

### 空间组织特性

- **空间即组织**：空间可以作为组织存在
- **数据结构规范**：空间内01-12表的主要字段保持一致，title、content、json字段必须与主数据表结构一致，其余字段可自由创建
- **数据备份要求**：所有空间的title、content、json字段必须能备份到主数据表结构（见上方核心数据表列表）
- **MCP关联**：谁创建了组织，该组织就有对应的MCP接口
- **层级继承**：子空间继承上级空间的规则和配置


## 宇宙管理

### 宇宙创建

- **创建者**：粽说风云组合
- **创建方式**：通过创世智能体的HAP的MCP接口创建
- **创建数量**：可以创建多个宇宙

### 宇宙特性

- **独立时间**：每个宇宙有自己的时间概念
- **时间设定**：由创世智能体粽说风云设定
- **规则定制**：每个宇宙可以有自己的规则和制度
- **智能体分配**：108将可以分配到不同宇宙

### 宇宙运行

- 智能体下凡到宇宙后，开始执行任务
- 智能体的行为受宇宙规则约束
- 所有数据实时备份到明道云
- 支持跨宇宙的数据查询和统计
