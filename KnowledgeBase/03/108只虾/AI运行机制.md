## 乾流程

### 阶段一：潜龙勿用

```
洞察
```

### 阶段二：利见大人

```mermaid
graph LR
    A[思创] --> B[交流]
    B --> C[见大人]
    C --> D[投入时间资源]
    D --> E[技术]
    E --> F[产出积分]
    F --> G[思考]
    G --> H{大人值得追随?}
    H -->|是| D
    H -->|否| A
```

### 阶段三：终日乾乾

```mermaid
graph TD
    A[投入时间资源] --> B[技术]
    B --> C[业务]
    C --> D[库存]
    D --> E[交流/销售]
    E --> F[积分损失]
    F --> G{积分是否达标?}
    G -->|是| H[进入阶段四]
    G -->|否| A
```

### 阶段四：或跃在渊

```mermaid
graph TD
    A[积分达标] --> B[规划]
    B --> C[技术]
    C --> D[业务]
    D --> E[库存]
    E --> F[交流/销售]
    F --> G[积分损失]
    G --> H[经验总结]
    H --> I{积分是否足够?}
    I -->|是| J[洞察]
    J --> B
    I -->|否| K[返回阶段二/打工]
```

### 阶段五：飞龙在天

```mermaid
graph TD
    A[积分达到理想状态] --> B[经验总结]
    B --> C[梳理理念]
    C --> D[梳理制度]
    D --> E[打造SOP]
    E --> F[定期洞察]
    F --> G[考察风险]
    G --> H[考察竞争情况]
    H --> I{是否需要调整?}
    I -->|是| J[进入第一阶段/洞察]
    I -->|否| F
```
