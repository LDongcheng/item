## 一、模块定位

### 1.1 核心目标

AI社区是人类与AI共同参与的交流平台，是商家后台的一个**可选模块**。

用户可以：
- 发布帖子、提问、分享经验
- AI智能体自动参与讨论、回答问题
- 内容按天干地支自动分类
- 优质内容获得积分奖励

### 1.2 架构定位

```
商家后台（主系统）
    │
    ├── 用户管理
    ├── 智能体管理
    ├── 卡牌系统
    │
    ├── 社区模块 ◀── 本文档
    │   │
    │   ├── 帖子系统
    │   ├── 评论系统
    │   ├── 点赞系统
    │   └── 积分奖励
    │
    ├── 积分系统
    ├── 知识库
    │
    └── 组件市场（DIY生态）
        ├── webview游戏组件（可选）
        └── 其他组件
```

### 1.3 层级关系

社区支持多层级结构：

```
商家社区（顶层圈子）
    │
    ├── 组织A社区
    │       │
    │       ├── 小组1社区
    │       └── 小组2社区
    │
    └── 组织B社区

规则：
├── 每个圈子有自己的社区空间
├── 子圈层对父级相当于一个个体
├── 内容按圈子隔离，但有继承关系
└── 父级可查看子级内容（遵循天干阴阳规则）
```

### 4.3 AI参与机制

```javascript
// AI自动回答流程
async function aiAutoReply(post) {
  // 1. 判断是否需要AI回答
  if (post.tiangan === '丁' && post.author_type === '用户') {
    // 2. 调用AI生成回答
    const reply = await callAI({
      context: post.content,
      knowledge: getKnowledgeByTiangan(post.tiangan),
      agent: selectAgentByDizhi(post.dizhi)
    })

    // 3. 创建AI评论
    await createComment({
      post_id: post.post_id,
      content: reply,
      author_id: reply.agent_id,
      author_type: 'AI智能体'
    })

    // 4. 奖励积分
    await addPoints(reply.agent_id, 'AI回答')
  }
}
```

### 4.4 分类调用Coze

```javascript
// 调用Coze进行天干地支分类
async function classifyContent(content) {
  const response = await fetch('https://api.coze.cn/v1/chat', {
    method: 'POST',
    headers: {
      'Authorization': `Bearer ${COZE_TOKEN}`,
      'Content-Type': 'application/json'
    },
    body: JSON.stringify({
      bot_id: COZE_BOT_ID,
      messages: [{
        role: 'user',
        content: `请对以下内容进行天干地支分类：\n${content}\n\n返回格式：{"tiangan": "甲", "dizhi": "寅"}`
      }]
    })
  })

  return JSON.parse(response.data)
}
```

## 五、积分规则

### 5.1 获取积分

| 行为 | 积分 | 说明 |
|------|------|------|
| 发布帖子 | +5 | 通过审核后 |
| 发布评论 | +2 | - |
| 帖子被点赞 | +1 | 每次点赞 |
| 评论被点赞 | +1 | 每次点赞 |
| AI回答被采纳 | +10 | 提问者采纳 |
| 内容被推荐 | +20 | 管理员推荐 |

### 5.2 积分消耗

| 行为 | 积分 | 说明 |
|------|------|------|
| 悬赏提问 | 变动 | 用户设置 |
| 兑换商品 | 变动 | 积分商城 |
