# 4维(丁)交流系统

> Agent通过此维度进行通信，是12维架构的核心运转机制

---

## 通信架构

```
┌─────────────────────────────────────────────────┐
│           WebSocket 桥接服务 (端口3011)          │
│                   server.js                      │
└────────┬───────────────┬────────────────────────┘
         │               │
    ┌────▼────┐     ┌────▼────┐
    │ Agent A │     │ Agent B │
    │ webview │     │ 小程序   │
    └─────────┘     └─────────┘
         │               │
         └─── 消息广播 ───┘
```

---

## 通信协议

### 连接方式

```
ws://服务器地址:3011/ws?client={agentId}
```

**参数**：
- `client`: Agent唯一标识ID

### 消息格式

```json
{
  "type": "消息类型",
  "from": "发送者ID",
  "to": "接收者ID（可选，空则广播）",
  "dimension": "关联维度（1-12）",
  "action": "具体动作",
  "data": { /* 具体数据 */ },
  "time": "ISO时间戳"
}
```

---

## 消息类型定义

### 1. 状态消息

```json
{
  "type": "status",
  "from": "agent_001",
  "dimension": 1,
  "action": "skill_update",
  "data": {
    "skill": "移动控制",
    "level": 2,
    "status": "active"
  }
}
```

### 2. 指令消息

```json
{
  "type": "command",
  "from": "agent_control",
  "to": "npc_001",
  "dimension": 3,
  "action": "move",
  "data": {
    "targetX": 10,
    "targetY": 5,
    "speed": "normal"
  }
}
```

### 3. 请求消息

```json
{
  "type": "request",
  "from": "agent_002",
  "to": "agent_001",
  "dimension": 9,
  "action": "query_info",
  "data": {
    "query": "获取用户画像",
    "userId": "user_123"
  }
}
```

### 4. 响应消息

```json
{
  "type": "response",
  "from": "agent_001",
  "to": "agent_002",
  "dimension": 10,
  "action": "user_profile",
  "data": {
    "userId": "user_123",
    "profile": { /* 用户数据 */ }
  }
}
```

### 5. 事件消息

```json
{
  "type": "event",
  "from": "system",
  "dimension": 7,
  "action": "goal_assigned",
  "data": {
    "goalId": "goal_001",
    "description": "完成像素编辑器开发",
    "deadline": "2026-04-25"
  }
}
```

## 维度与通信关联

| 维度 | 通信场景 | 典型消息 |
|------|----------|----------|
| 1维(寅)技能 | 技能状态同步 | status/skill_update |
| 2维(卯)想法 | 想法分享讨论 | event/idea_proposed |
| 3维(丙)业务 | 任务分配执行 | command/task_assign |
| 4维(丁)交流 | **核心通信层** | 所有消息类型 |
| 5维(庚)制度 | 规则通知 | event/rule_update |
| 6维(辛)价值观 | 价值决策 | request/value_check |
| 7维(壬)目标 | 目标下达 | event/goal_assigned |
| 8维(癸)计划 | 计划同步 | status/plan_update |
| 9维(丑)信息 | 信息查询 | request/query_info |
| 10维(辰)人脉 | 人脉请求 | request/profile |
| 11维(未)仓 | 文件共享 | event/file_shared |
| 12维(戌)复盘 | 复盘通知 | event/review_complete |

## Agent身份标识

### ID命名规范

```
{类型}_{编号}

类型:
- agent: 智能体
- npc: 虚拟角色
- user: 用户
- system: 系统
- org: 组织

示例:
- agent_001  (智能体1号)
- npc_soldier (NPC士兵)
- user_lin   (用户林东城)
- org_teamA  (组织团队A)
- system     (系统消息)
```

## 通信Skill模板

### skill: agent-communication.md

```markdown
# Agent通信Skill

## 能力描述
Agent通过WebSocket与其他Agent、用户、系统进行通信。

## 接口方法

### 1. 发送消息
sendMessage(type, to, dimension, action, data)

### 2. 接收消息
onMessage(callback)

### 3. 请求响应
request(to, dimension, action, data) → Promise

### 4. 广播状态
broadcastStatus(dimension, status)
```
