OpenClaw 项目开发规则

确保代码质量和项目一致性的开发指南

TypeScript + Express.js

📋项目规则概述

本文档定义了 OpenClaw 项目的开发规则、编码规范、架构原则和最佳实践。所有开发者必须遵循这些规则以确保代码质量和项目一致性。

🎯项目背景

💡 核心目标

为了更深刻理解 openclaw 这套源码，我们要复刻一个和（openclaw）功能完全一致的项目（openclaw_total），所以 openclaw_total 项目里面文件名称、对象名称、文件层级结构等要保持一致。我们尽可能功能一样。

开发策略：

  • 根据核心功能、难易度等逐步开发
  • 一步一步将练习项目和源代码保持一致
  • 每一步都要进行功能验证再进行下一步
  • 这样我才能对 openclaw 项目的维护和二开上面更加得心应手

2模块化设计

  • 单一职责：每个模块只负责一个功能
  • 高内聚低耦合：模块内部紧密相关，模块间依赖最小
  • 接口优先：优先使用接口定义模块契约
  • 依赖注入：使用依赖注入管理模块依赖

3事件驱动

  • 事件发布订阅：使用事件模式解耦模块
  • 异步处理：所有事件处理都是异步的
  • 错误隔离：事件处理错误不应影响其他处理器
  • 事件日志：记录所有重要事件

3观察者模式

TypeScript
class EventEmitter {
  private listeners: Map<string, Function[]> = new Map();

  on(event: string, callback: Function): void {
    if (!this.listeners.has(event)) {
      this.listeners.set(event, []);
    }
    this.listeners.get(event)!.push(callback);
  }

  emit(event: string, ...args: any[]): void {
    const callbacks = this.listeners.get(event);
    if (callbacks) {
      callbacks.forEach(callback => callback(...args));
    }
  }
}

3权限检查

TypeScript
interface Permission {
  user: string;
  action: string;
  resource: string;
}

class PermissionManager {
  private permissions: Permission[] = [];

  check(user: string, action: string, resource: string): boolean {
    return this.permissions.some(
      p => p.user === user && p.action === action && p.resource === resource
    );
  }

  grant(user: string, action: string, resource: string): void {
    this.permissions.push({ user, action, resource });
  }

  revoke(user: string, action: string, resource: string): void {
    this.permissions = this.permissions.filter(
      p => !(p.user === user && p.action === action && p.resource === resource)
    );
  }
}

// 使用权限检查
function executeCommand(user: string, command: string, resource: string) {
  if (!permissionManager.check(user, command, resource)) {
    throw new Error('Permission denied');
  }
  // 执行命令
}

class DataProcessor {

    // 永不清理缓存，导致内存泄漏
  }

// ✅ 推荐：定期清理缓存
class DataProcessor {
  private cache: Map<string, any> = new Map();
  private maxSize = 1000;

  processData(data: any) {
    if (this.cache.size >= this.maxSize) {
      this.cleanupCache();
    }
    this.cache.set(Date.now(), data);
  }

  private cleanupCache() {
    const entries = Array.from(this.cache.entries());
    entries.sort((a, b) => a[0] - b[0]);
    const toRemove = entries.slice(0, entries.length / 2);
    toRemove.forEach(([key]) => this.cache.delete(key));
  }
}

2并发控制

TypeScript
// ✅ 推荐：限制并发请求数
class RequestQueue {
  private queue: Array<() => Promise<any>> = [];
  private activeRequests = 0;
  private maxConcurrent = 10;

  async add(request: () => Promise<any>): Promise<any> {
    if (this.activeRequests >= this.maxConcurrent) {
      await new Promise(resolve => {
        this.queue.push(() => {
          resolve(this.add(request));
        });
      });
    }

    this.activeRequests++;
    try {
      return await request();
    } finally {
      this.activeRequests--;
      this.processQueue();
    }
  }

  private processQueue() {
    while (this.queue.length > 0 && this.activeRequests < this.maxConcurrent) {
      const next = this.queue.shift();
      next?.();
    }
  }
}

3缓存策略

TypeScript
// ✅ 推荐：使用缓存减少重复计算
class CacheManager {
  private cache: Map<string, { value: any; expiry: number }> = new Map();
  private defaultTTL = 60000; // 1分钟

  get(key: string): any | null {
    const entry = this.cache.get(key);
    if (!entry) return null;

    if (Date.now() > entry.expiry) {
      this.cache.delete(key);
      return null;
    }

    return entry.value;
  }

  set(key: string, value: any, ttl?: number): void {
    const expiry = Date.now() + (ttl || this.defaultTTL);
    this.cache.set(key, { value, expiry });
  }

  clear(): void {
    this.cache.clear();
  }
}

// 使用示例
const cache = new CacheManager();

function getUserData(userId: string): Promise<User> {
  const cached = cache.get(userId);
  if (cached) return cached;

  const userData = await fetchUserFromAPI(userId);
  cache.set(userId, userData);
  return userData;
}

3重试机制

TypeScript
// ✅ 推荐：指数退避重试
async function retryWithBackoff<T>(
  fn: () => Promise<T>,
  maxRetries = 3,
  baseDelay = 1000
): Promise<T> {
  let lastError: Error;

  for (let attempt = 0; attempt < maxRetries; attempt++) {
    try {
      return await fn();
    } catch (error) {
      lastError = error as Error;
      
      if (attempt < maxRetries - 1) {
        const delay = baseDelay * Math.pow(2, attempt);
        logger.warn(`Attempt ${attempt + 1} failed, retrying in ${delay}ms`);
        await new Promise(resolve => setTimeout(resolve, delay));
      }
    }
  }

  throw lastError!;
}

// 使用示例
const data = await retryWithBackoff(
  () => fetchUserData(userId),
  5,
  1000
);
