网关 (Gateway)

架构相关 · 架构阶段

🎯 一句话理解

网关就像是一个智能前台，所有来访的请求都要先经过它，它负责把请求引导到正确的服务那里去。

💡 形象比喻

🏨 酒店前台

想象你走进一家大酒店，前台接待员就是"网关"。你告诉前台你要去哪里（餐厅、健身房、客房），前台会指引你正确的方向，还会检查你的身份、安排电梯等等。

🚦 交通枢纽

网关就像一个交通枢纽，所有车辆（请求）都要先到这里，然后被分配到不同的道路（服务）上去。它还能在高峰期分流车辆，避免某条路太堵。

📝 代码示例

一个简单的网关路由配置：

// 网关路由配置示例
const routes = {
  '/api/users': 'user-service:8001',
  '/api/orders': 'order-service:8002',
  '/api/payments': 'payment-service:8003'
};

function handleRequest(request) {
  const targetService = routes[request.path];
  return forwardTo(targetService, request);
}

  • 常见网关：Nginx、Kong、Spring Cloud Gateway
  • 理解网关在微服务架构中的关键作用
