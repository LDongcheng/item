路由 (Routing)

架构相关 · 架构阶段

🎯 一句话理解

路由就像快递分拣中心，根据包裹上的地址标签，把每个请求送到正确的目的地。

💡 形象比喻

📦 快递分拣中心

想象一个快递分拣中心，每件包裹都有地址标签。路由系统就像分拣员，看到"北京"就放到北京的车上，看到"上海"就放到上海的车上，确保每件包裹都能准确送达。

🚦 交通导航

路由就像导航软件，根据你的目的地（URL路径），为你规划最佳路线，把你引导到正确的服务那里。不同的目的地走不同的路线。

⚖️ 权重路由

按比例分配流量

🔄 动态路由

运行时动态更新规则

📝 代码示例

一个简单的路由配置：

// 路由规则配置
const routes = {
  '/api/users': {
    service: 'user-service',
    methods: ['GET', 'POST']
  },
  '/api/orders': {
    service: 'order-service',
    methods: ['GET', 'POST', 'PUT']
  }
};
