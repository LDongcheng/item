进程 Process

进程是正在运行的程序实例，每个进程都有独立的内存空间和系统资源

🏭 生活中的类比

进程 = 工厂里的独立车间

想象一个工厂里有多个车间，每个车间（进程）都有自己的：

  • • 📦 原料仓库（内存空间）
  • • 🔧 生产设备（系统资源）
  • • 👷 工作人员（执行线程）
  • • 📋 工作编号（PID）

进程 = 手机上的App

你手机上同时运行的微信、抖音、浏览器，每个都是独立的进程：

  • • 📱 各自占用内存
  • • 🔄 可以同时运行
  • • 🚫 一个崩溃不影响其他
  • • 📊 任务管理器能看到PID

核心特性

🔒
独立运行，互不干扰
每个进程有自己独立的内存空间，一个进程崩溃不会影响其他进程
📡
可通过网络/管道通信
进程之间可以通过IPC（进程间通信）机制交换数据
🆔
每个进程有唯一PID
操作系统为每个进程分配唯一的进程标识符
💾
独立的系统资源
每个进程拥有独立的文件描述符、环境变量等资源

代码示例 

# Python 中查看当前进程信息
import os

# 获取当前进程PID
print(f"当前进程PID: {os.getpid()}")

# 获取父进程PID
print(f"父进程PID: {os.getppid()}")

# 创建子进程
pid = os.fork()
if pid == 0:
    print("这是子进程")
else:
    print(f"这是父进程，子进程PID: {pid}")
