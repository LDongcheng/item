SkillsInstallPreferences
├─ preferBrew: boolean
└─ nodeManager: "npm" | "yarn" | "pnpm" | "bun"

唯一实现函数：resolveSkillsInstallPreferences

函数源码

export function resolveSkillsInstallPreferences(
config?: OpenClawConfig
): SkillsInstallPreferences {
// 读取原始配置
const raw = config?.skills?.install;
// 默认优先使用 brew
const preferBrew = raw?.preferBrew ?? true;
// 解析包管理器
const managerRaw = typeof raw?.nodeManager === "string"
? raw.nodeManager.trim() : "";
const manager = managerRaw.toLowerCase();
// 验证并选择有效的管理器
const nodeManager =
manager === "pnpm" || manager === "yarn" ||
manager === "bun" || manager === "npm"
? manager : "npm";
return { preferBrew, nodeManager };
}

处理流程

1 读取 config.skills.install
2 提取 preferBrew (默认 true)
3 规范化 nodeManager 字符串
4 验证是否为有效管理器
5 返回 { preferBrew, nodeManager }

核心概念词汇表

Skill

可扩展的能力模块，提供特定功能如代码分析、文档生成等

SkillEntry

技能条目，包含技能的配置信息和元数据

SkillSnapshot

技能快照，运行时的技能状态快照

preferBrew

是否优先使用 Homebrew 安装依赖

nodeManager

Node.js 包管理器：npm/yarn/pnpm/bun

EnvOverrides

环境变量覆盖，技能可以修改运行环境

workspace.js
