用生活场景理解它

🍱

像餐厅菜单

工具就像菜单上的菜品，Profile 就像套餐——「精简套餐」只有基础菜，「编码套餐」有开发工具，「完整套餐」可以点所有菜

🎮

像游戏技能树

每个工具是一项技能，不同职业（Profile）有不同的技能配置。法师有魔法技能，战士有战斗技能，全职业可以学所有技能

🔐

像权限系统

工具是系统功能，Profile 是角色。不同角色有不同的功能权限，管理员可以访问所有功能，普通用户只能用基础功能

核心数据结构

ToolProfileId

定义四种工具配置方案的身份标识

export type ToolProfileId =
"minimal" // 精简模式
| "coding" // 编码模式
| "messaging" // 消息模式
| "full"; // 完整模式

CoreToolDefinition

每个工具的完整元数据定义

type CoreToolDefinition = {
id: string; // 工具唯一标识
label: string; // 显示名称
description: string; // 功能描述
sectionId: string; // 所属分类
profiles: ToolProfileId[]; // 所属 Profile
includeInOpenClawGroup?: boolean;
};

ToolProfilePolicy

定义工具的允许/拒绝策略

type ToolProfilePolicy = {
allow?: string[]; // 允许的工具列表
deny?: string[]; // 拒绝的工具列表
};
// full 模式: 空对象 = 无限制
// coding 模式: allow: [工具列表]

CORE_TOOL_GROUPS

工具分组映射，支持批量引用

export const CORE_TOOL_GROUPS = {
"group:openclaw": [ // OpenClaw 核心工具
"web_search", "browser", ...
],
"group:fs": [ // 文件系统工具
"read", "write", "edit", ...
],
// ... 其他分组
};
