Core Runtime Engine

run.ts

OpenClaw 的「心脏引擎」—— 负责整个 AI Agent 运行周期的编排、错误恢复和资源管理

用生活场景理解它

🎮

像游戏引擎的主循环

就像游戏每帧都要处理输入、更新状态、渲染画面，这个文件管理 AI 每次对话的完整生命周期——接收请求、调用模型、处理错误、返回结果

🏥

像医院分诊系统

当遇到「病人」（错误）时，系统会自动判断严重程度、尝试不同治疗方案（换认证、降级思考模式、压缩上下文），直到问题解决或所有方案耗尽

🔋

像智能电源管理

管理多个「电池」（认证配置），监控电量状态（冷却期），在某个电池耗尽时自动切换备用电源，确保系统持续运行
