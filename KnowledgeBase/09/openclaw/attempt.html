Single Run Attempt

attempt.ts

OpenClaw 的「单次尝试执行器」—— 负责一次完整的 AI Agent 对话轮次的准备、执行与清理

用生活场景理解它

🎬

像电影的一场戏

run.ts 是整部电影，attempt.ts 是其中一场戏——从搭景（准备环境）、选角（加载工具）、到拍摄（执行对话）、最后杀青（清理资源），完整的一场

🍳

像做一道菜

备菜（解析配置）→ 热锅（初始化会话）→ 调味（注入提示词）→ 翻炒（执行对话）→ 装盘（返回结果）→ 洗锅（清理资源），每步都有讲究

🎯

像一次航天发射

发射前检查（环境验证）、倒计时（钩子执行）、点火升空（发送 prompt）、任务监控（超时处理）、返回舱回收（结果收集）、发射台清理（资源释放）

多提供商适配机制

O

Ollama 兼容

// 检测 Ollama 兼容提供商
if (isOllamaCompatProvider(model)) {
// 本地 localhost:11434
// 或远程 Ollama OpenAI 兼容端点
// 注入 num_ctx 参数
wrapOllamaCompatNumCtx(streamFn, ctx);
}
  • • 自动检测本地/远程 Ollama 端点
  • • 注入 num_ctx 参数避免默认 4096 限制
  • • 使用原生 /api/chat 接口支持工具调用
WS

OpenAI WebSocket

if (api === "openai-responses") {
createOpenAIWebSocketStreamFn(
apiKey,
sessionId,
{ signal: abortController.signal }
);
}
  • • 实时双向通信降低延迟
  • • 支持流式响应和中断控制
  • • 会话结束自动释放 WebSocket 连接
X

xAI / Grok

if (isXaiProvider(provider)) {
// xAI 返回的工具调用参数可能包含
// HTML 实体编码，需要解码
wrapStreamFnDecodeXaiToolCallArguments(
streamFn
);
}
  • • 解码 HTML 实体（& → & 等）
  • • 确保工具调用参数正确解析
  • • 兼容 Grok 模型的特殊输出格式
A

Anthropic / Claude

// 清理 Anthropic 拒绝测试字符串
scrubAnthropicRefusalMagic(prompt);
// 验证轮次格式
validateAnthropicTurns(messages);
// 负载日志记录
createAnthropicPayloadLogger(...);
  • • 过滤敏感测试触发词
  • • 验证消息轮次格式
  • • 记录详细负载用于调试
