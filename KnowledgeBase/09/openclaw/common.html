common.ts

OpenClaw 的「工具百宝箱」—— 提供参数解析、错误处理、结果构建等通用工具函数

用生活场景理解它

📦

像快递分拣中心

参数读取函数就像分拣员，把各种格式的包裹（参数）分类处理——字符串放左边，数字放右边，数组单独堆

🚦

像交通信号灯

ActionGate 就像信号灯控制——绿灯允许通行，红灯禁止通行，没有灯时按默认规则走

🎁

像礼物包装站

结果构建函数就像包装站——把原始数据（内容）包成漂亮的礼盒（标准格式），贴上标签

Snake Case 自动转换

系统支持 camelCase 和 snake_case 两种命名风格自动转换，确保参数名兼容性

错误类型层次结构

403 ToolAuthorizationError

ActionGate 操作门控

ActionGate 用于控制特定操作是否允许执行，支持默认值和显式配置

操作配置

readFile
writeFile
executeCommand

门控结果

const gate = createActionGate(actions);
gate("readFile"); // ?
gate("writeFile"); // ?
gate("executeCommand"); // ?

核心函数一览

readStringParam

读取字符串参数，支持必填、修剪、空值检查

readNumberParam

读取数字参数，支持整数转换和严格模式

readStringArrayParam

读取字符串数组，支持单值转数组

jsonResult

构建 JSON 格式的工具返回结果

imageResult

构建包含图像的工具返回结果

imageResultFromFile

从文件读取并构建图像结果

createActionGate

创建操作门控函数

wrapOwnerOnlyToolExecution

包装所有者专用工具执行

parseAvailableTags
