进程

进程是正在运行的程序实例。每个进程都有独立的内存空间和系统资源。

独立运行，互不干扰
可通过网络/管道通信
每个进程有唯一 PID
// 类比理解
进程 = 工厂里的独立车间

网关

网关是一个中转站，负责接收请求、路由转发、负载均衡和响应返回。

统一入口点
请求路由与分发
协议转换与安全控制
// 类比理解
网关 = 酒店前台 / 机场塔台

Pi 编程智能体

Pi 是 Programming Intelligence 的缩写，指专门处理编程任务的 AI Agent。

代码生成与分析
问题诊断与修复
独立服务，可扩展
// 类比理解
智能体 = 专业技师 / 专家顾问

本地部署

所有进程运行在同一台机器上，通过 localhost 通信。

✓
低延迟
本地通信速度快
✓
数据安全
数据不离开本机
!
资源受限
受本地硬件限制

远程部署

进程分布在不同服务器，通过网络 API 通信。

✓
弹性扩展
可随时增加智能体实例
✓
高可用
多节点容错
!
网络开销
需要考虑延迟和安全

如何选择?

选择本地部署：
  • • 开发测试阶段
  • • 数据隐私要求高
  • • 单机资源足够
选择远程部署：
  • • 生产环境服务
  • • 需要高并发处理
  • • 多用户协作场景
