代码示例

const express = require('express');
const app = express();
// 中间件 1: 解析 JSON
app.use(express.json());
// 中间件 2: 日志记录
app.use((req, res, next) => {
console.log(req.method, req.path);
next(); // 传递给下一个中间件
});
// 路由处理器
app.get('/users', (req, res) => {
res.json({ users: [] });
});
// 错误处理中间件 (4个参数)
app.use((err, req, res, next) => {
res.status(500).json({ error: err.message });
});

核心要点：

  • • next() 调用才会继续执行下一个中间件
  • • 不调用 next() 则请求-响应周期结束
  • • 4 个参数的函数被识别为错误处理中间件

架构层次图

核心对象：req 和 res

req 请求对象

req.method // 'GET', 'POST'...
req.url // '/users/123'
req.params // { id: '123' }
req.query // { page: '1' }
req.body // POST 数据
req.headers // 请求头对象
req.cookies // Cookie 对象
req.ip // 客户端 IP

res 响应对象

res.status(200) // 设置状态码
res.json(data) // JSON 响应
res.send(text) // 文本响应
res.render(view) // 渲染模板
res.redirect(url) // 重定向
res.set(header) // 设置响应头
res.cookie(...) // 设置 Cookie
res.end() // 结束响应

核心概念词汇表

Middleware

中间件，处理请求-响应周期的函数链

Router

路由器，将请求分发到对应处理器

Route Params

路由参数，如 /users/:id 中的 id

Error Handler

错误处理中间件，4 个参数的函数

app.use()

注册中间件，匹配所有路径

app.METHOD()

注册路由，匹配特定 HTTP 方法

next()

调用下一个中间件的函数

express.Router()

创建可挂载的模块化路由器
