选项定义系统

选项类型

-f, --file Boolean

布尔选项，存在即为 true

-n, --name <value> Required

必填值选项，尖括号语法

-o, --output [value] Optional

可选值选项，方括号语法

-c, --config <path> Coercion

值处理函数，验证或转换

定义代码

const { program } = require('commander');
program
.name('mycli')
.description('My CLI tool')
.version('1.0.0')
// 布尔选项
.option('-d, --debug', '启用调试模式')
// 必填值选项
.option('-f, --file <path>', '文件路径')
// 可选值选项
.option('-o, --output [path]', '输出路径')
// 带默认值
.option('-p, --port <number>', '端口号', 3000)
.parse();

命令与子命令系统

// 定义子命令
program
.command('install <package>')
.alias('i')
.description('安装依赖包')
.option('-D, --save-dev', '保存为开发依赖')
.action((pkg, options) => {
console.log(`安装 ${pkg}`);
});

核心概念词汇表

program

顶级命令实例，整个 CLI 的入口

command

子命令定义，支持嵌套

option

选项定义，短名和长名组合

argument

位置参数定义，必填或可选

action

命令执行的处理函数

parse

解析 process.argv 数组

alias

命令别名，如 install → i

coercion

选项值转换/验证函数
