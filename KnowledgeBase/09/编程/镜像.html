镜像的三大核心特性

理解这三点，你就真正懂镜像了

只读不可变

镜像一旦创建，就不能修改。就像你买到的预制菜配方是固定的。

想修改？ 只能基于旧镜像构建新镜像

无限复制

一个镜像可以创建无数个容器，每个容器都从相同的"模板"诞生。

镜像

分层存储

镜像由多个只读层堆叠而成，每层记录变化。公共层可以共享。

分层的好处

✓
共享公共层

多个镜像可以共享相同的基础层，节省磁盘空间

✓
加速构建

未变化的层会被缓存，只重新构建修改的部分

✓
快速分发

拉取镜像时只需下载本地没有的层

Dockerfile

# 基础镜像
FROM node:18-alpine
# 设置工作目录
WORKDIR /app
# 复制依赖文件
COPY package*.json ./
# 安装依赖
RUN npm install
# 复制源代码
COPY . .
# 暴露端口
EXPOSE 3000
# 启动命令
CMD ["npm", "start"]

镜像 vs 容器：一句话区分

镜像 Image

死的、只读的模板
预制菜套餐

容器 Container

活的、可运行实例
正在吃的外卖

镜像 是模具，容器 是产品。
一个模具可以生产无数个一模一样的产品。
